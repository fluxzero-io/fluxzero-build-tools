# Security Policy

This policy covers `fluxzero-build-tools`. The
[Fluxzero security policy](https://github.com/fluxzero-io/.github/blob/main/SECURITY.md)
describes supported versions, maintenance, and coordinated disclosure.
For upstream vulnerabilities in a fork, follow the upstream project's policy.

## Reporting a vulnerability

Use this repository's **Security > Report a vulnerability** action when available.
Otherwise report privately through the
[Fluxzero security reporting channel](https://github.com/fluxzero-io/.github/security/advisories/new).
Do not open a public issue or pull request for an undisclosed vulnerability.

Include the affected repository, version or commit, platform, expected impact,
and a minimal reproduction. Remove credentials, production secrets, and customer
data from examples and logs. Maintainers coordinate triage, remediation, and
disclosure privately with the reporter.
